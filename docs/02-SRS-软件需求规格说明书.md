## 1. 引言

### 1.1 目的

本文档定义「墨匠 InkCraft」V1.0（MVP）的软件需求，作为设计、开发、测试与验收的依据。预期读者：产品、开发、测试、外包协作方。

### 1.2 范围

V1.0 覆盖：项目/书架管理、创世向导、设定集、三层大纲、章节编辑器、AI 生成（续写/润色/扩写）、RAG 上下文引擎、章后记忆归档、导出、设置与模型管理。不含：云同步、协作、一致性检查与伏笔看板（V1.x）、多分支剧情（V2.0）。

### 1.3 系统边界

- **系统内**：Windows 桌面客户端（本地数据库、本地文件、本地嵌入推理（可选））。
- **系统外（依赖）**：用户配置的大模型 API 服务（OpenAI 兼容端点 / Ollama 本地服务）、可选的 API 嵌入服务。除上述端点外软件不主动发起任何网络请求（升级检查默认关闭，可在设置开启）。

### 1.4 术语与缩写

| 术语 | 定义 |
|---|---|
| Codex / 设定集 | 结构化存储的世界观与角色等设定条目库 |
| 章纲 | 单章的写作计划：目标、情节点、出场角色、伏笔、钩子 |
| RAG | 检索增强生成：续写前按需检索相关设定/前文并注入提示词 |
| 上下文组装器 | 将各信息区块按 Token 预算装配为最终提示词的组件 |
| Token 预算 | 单次请求输入上下文的 token 分配方案，按区块限额 |
| 章后归档 | 章节定稿后生成摘要、更新角色状态、登记伏笔并增量索引的动作 |
| BYOK | Bring Your Own Key，用户自备模型 API Key |
| 快照 | AI 生成前的正文自动备份，用于回滚 |

## 2. 总体描述

### 2.1 产品视角

独立桌面应用，单机运行；数据模型以「一本书 = 一个项目（SQLite 单库文件）」组织，书架管理多个库文件。

### 2.2 用户特征

见 PRD 第 2 章。假设用户：会常规电脑操作；不理解提示词工程；对"丢稿"零容忍。

### 2.3 运行环境

- Windows 10 19044+ / Windows 11，x64；4 GB 内存起步（推荐 8 GB+）；
- 需要用户自行具备至少一个模型 API Key，或本机安装 Ollama；
- 磁盘：软件本体 ≤ 300 MB；单本书库文件按 100 万字估算 ≤ 200 MB（含向量索引）。

### 2.4 约束

- 作品内容与设定默认仅存本地；发送给模型服务的内容仅限本次请求组装的上下文；
- 中文为主要语言（界面、提示词、分词、嵌入均按中文优化）；
- Electron 桌面框架（见开发文档选型），离线可用（编辑、检索、导出不依赖网络）。

### 2.5 假设与依赖

- 模型服务提供 OpenAI 兼容的 chat/completions 与流式 SSE；
- 用户理解"AI 产出为草稿，需人工审校"（首次使用引导中明示）。

## 3. 功能需求

> 编号规则：`FR-<模块>-<序号>`。优先级 P0/P1/P2 与 PRD 一致；本版只展开 P0 的详细规格，P1/P2 概述并指向 PRD。

### 3.1 项目与书架管理（LIB）

**FR-LIB-01 书架管理（P0）**
- 描述：列出本机所有书籍项目（卡片：书名/题材/字数/最近编辑时间/封面缩略），支持创建、打开、重命名、删除（删除需二次确认并可选导出备份）、归档。
- 输入/输出：操作 → 书架列表刷新。
- 验收标准：
  1. 新建书在 ≤2s 内进入工作台；
  2. 删除操作必须经过"输入书名确认"或等强度确认；
  3. 书架支持按最近编辑排序，记住上次打开的书。

**FR-LIB-02 书籍元信息（P0）**
- 描述：书名、题材（枚举+自定义）、目标字数、文风指令（自由文本，注入续写提示词）、一句话梗概。
- 验收：文风指令修改后，下一次续写提示词即生效（可在提示词透明度视图中验证）。

### 3.2 创世向导（GEN）

**FR-GEN-01 分步向导（P0）**
- 描述：新建书后进入四步向导：① 题材与灵感（选择题材模板 + 自由描述核心创意 + 关键词）② 世界观生成 ③ 主角与核心角色生成 ④ 总纲生成。每一步 AI 产出后均可编辑、重新生成（单步重roll，不推翻其他步骤）。
- 验收：
  1. 每步产出以结构化表单呈现，可直接编辑保存进设定集；
  2. 单步"重新生成"保留人工已修改内容需先确认；
  3. 向导可中途退出，已保存内容不丢失，可从书架重新进入继续。

**FR-GEN-02 世界观生成（P0）**
- 输出结构：世界背景、力量/规则体系、社会结构、地理概览、核心禁忌、金手指定义（若有）。
- 验收：产出保存为 Codex 条目（type=世界观，importance=常驻）；字数 500～1500 可配。

**FR-GEN-03 角色卡生成（P0）**
- 输出结构：姓名（含备选）、身份、外貌特征（可复用锚点）、性格、动机与目标、说话风格、与主角关系、初始状态。
- 验收：保存为 Codex 角色（type=character）；支持一次生成 3～5 个角色；姓名与已有条目查重。

**FR-GEN-04 总纲生成（P0）**
- 输出结构：故事梗概（300 字内）、主题、主线冲突、分卷走向（每卷一段）、结局构想。
- 验收：保存为大纲根节点（level=book）；卷走向可直接"生成卷纲"复用。

### 3.3 设定集（CX）

**FR-CX-01 条目管理（P0）**
- 描述：条目类型：character / location / faction / item / rule / world / custom。字段：名称、别名（多个）、类型、正文（Markdown）、重要性（常驻/检索）、标签。支持搜索、按类型过滤、引用计数。
- 验收：
  1. 条目保存后进入 RAG 索引（延迟 ≤ 10s，后台）；
  2. 别名参与关键词检索与强制召回；
  3. 删除条目需确认，且在相关章节有引用时提示影响范围。

**FR-CX-03 角色状态快照（P1，概要）**：按章节号记录角色状态（JSON），续写时取"当前写作章节之前"的最新快照注入。详见开发文档 6.3。

### 3.4 大纲体系（OL）

**FR-OL-01 三层大纲树（P0）**
- 描述：总纲（book）→ 卷（volume）→ 章纲（chapter）三级树；左侧导航与写作页联动；章纲与正文章节一一对应。
- 验收：新建章纲可同步创建空白正文章节（可选双向）；删除章纲不删正文（需确认提示）。

**FR-OL-02 章纲结构（P0）**
- 字段：章节号、标题、本章目标、情节要点（列表）、出场角色（关联 Codex）、伏笔（埋设/回收，多选）、情绪节奏（如"压抑→爆发"）、章末钩子。
- 验收：所有字段在续写提示词组装时可被引用（见 T-06 模板变量）。

**FR-OL-03 AI 生成大纲（P0）**
- 描述：由总纲生成卷纲（逐卷或全部）；由卷纲+上下文生成批量章纲（一次 ≤ 30 章，防超时与漂移）；单章纲细化。
- 验收：
  1. 批量生成以卷为单位分批请求（每批 ≤ 10 章拼接上下文）；
  2. 生成产出为"待确认"状态，作者逐条接受/修改后才生效；
  3. 生成过程中可取消，已完成批次保留。

### 3.5 章节编辑器（ED）

**FR-ED-01 三栏工作台（P0）**
- 描述：左栏（章节树+大纲导航，可折叠）；中栏（正文编辑器）；右栏（AI 面板：续写指令/生成参数/检索命中预览，可切换设定集速查）。布局可调，状态持久化。
- 验收：1280×720 分辨率下三栏可用不遮挡；1920×1080 默认布局合理。

**FR-ED-02 编辑器（P0）**
- 描述：所见即所得段落编辑；中文字数统计（汉字计数口径）；自动保存（防抖 ≤ 5s + 失焦即存）；章节标题与正文分区。
- 验收：
  1. 输入过程无可见卡顿（100 万字项目下打字延迟 < 50ms）；
  2. 断电/强杀进程后重启，丢失内容 ≤ 最近 5 秒输入；
  3. 字数统计与 Word 中文口径一致（±1%）。

**FR-ED-03 划词 AI 工具（P0）**
- 描述：选中文本浮出工具条：润色、改写、扩写、缩写（扩写可在弹窗给方向指令）。产出以 diff 预览呈现，可采纳/重试/取消。
- 验收：操作仅针对选区，不触碰选区外文本；采纳后保留快照可撤销（Ctrl+Z 与快照面板双重保障）。

**FR-ED-04 AI 续写（P0，核心）**
- 描述：光标处点击"续写"（快捷键 Ctrl+Enter）。流程：RAG 上下文组装 → 提示词渲染 → 流式生成 → 以浅色草稿态插入光标处。生成中可随时停止，保留已生成部分。支持连续多次续写，每次自动带上前次生成结果作为正文尾部。
- 验收：
  1. 首字显示延迟（API 正常时）< 3s；
  2. 中断后正文处于可编辑状态，已生成内容保留；
  3. 连续第 2 次续写不重复第 1 次内容（提示词中的正文尾部已更新）；
  4. 生成期间用户不可编辑正文尾部区域（锁定光标之后），防止冲突；
  5. 失败（网络/限流）时给出明确错误与重试按钮，不产生半截垃圾插入。

**FR-ED-05 版本快照（P0）**
- 描述：每次 AI 生成前自动保存正文快照；快照面板列表（时间+操作类型），支持预览 diff、恢复。
- 验收：快照存储增量化（仅差异），单书快照总量可控（默认保留最近 200 个，可配置）。

### 3.6 AI 生成与模型管理（AI）

**FR-AI-01 多供应商接入（P0）**
- 描述：Provider 配置（名称、Base URL、API Key、默认模型列表）；协议为 OpenAI 兼容 `/chat/completions`（含流式）；Ollama 以其兼容端点接入。
- 验收：
  1. 新增 Provider 有"连通性测试"（列出可用模型为通过）；
  2. 同一 Provider 支持配置多个模型并分别测试；
  3. API Key 在磁盘上以 DPAPI 加密存储，配置文件中不可见明文。

**FR-AI-02 模型分工（P0）**
- 描述：为功能场景指定模型：创世 / 大纲 / 续写 / 润色 / 摘要与提取。默认可全部相同。
- 验收：切换某场景模型立即生效；生成记录（日志）中记录所用模型。

**FR-AI-03 任务队列与可靠性（P0）**
- 描述：AI 请求进入队列（同书串行、跨书可并行 ≤ 2）；支持取消；失败自动重试 ≤ 2 次（指数退避）；流式输出中途断线不重试整个请求，保留已收内容并提示。
- 验收：关闭窗口时进行中的任务有确认提示；应用崩溃重启后队列恢复（任务元数据持久化）。

**FR-AI-05 提示词模板中心（P0）**
- 描述：列出全部内置模板（13 个，见提示词模板库）；查看/编辑/另存为自定义/恢复默认；模板变更带版本号。
- 验收：编辑器支持变量提示（列出可用变量）；模板保存时做变量合法性校验（未知变量警告）；生成时使用该书生效的模板版本。

**FR-AI-06 提示词透明度（P1，概要）**：每次生成后可查看「实际发送的完整提示词」「各区块 token 占用」「检索命中明细（来源+得分）」。

### 3.7 RAG 上下文引擎（RG，核心）

**FR-RG-01 多源索引（P0）**
- 描述：索引对象与切片粒度：
  1. Codex 条目（按条目，含别名元数据）；
  2. 章节正文（按场景切片，目标 400～800 字/片，重叠 50～100 字；携带元数据：章节号、出场实体、情节点标签）；
  3. 章节摘要 / 卷摘要（整条为一片）；
  4. 伏笔条目（整条一片）。
- 验收：新建书后可触发全量重建；重建 10 万字项目 < 60s（API 嵌入）或 < 5min（本地嵌入）。

**FR-RG-02 混合检索（P0）**
- 描述：向量检索（cosine）+ 关键词检索（FTS5，中文 trigram）双通道；融合得分；**强制召回规则**：本章纲声明的出场角色卡必进上下文；查询中出现且命中 Codex 的专有名词条目必进。
- 验收（评测集）：
  1. 自建评测集（≥ 50 条查询，人工标注期望命中）召回率@5 ≥ 80%；
  2. 角色别名（如"小聋子"→ 主角）可命中正确角色卡；
  3. 检索单次延迟（10 万字库）< 500ms。

**FR-RG-03 上下文组装器（P0）**
- 描述：按预算表装配区块（世界观常驻卡/卷纲/章纲/角色卡/前文摘要/正文尾部/伏笔/RAG 补充/用户指令），总预算按当前模型上下文自动缩放；超限按优先级裁剪 P2→P1。
- 验收：
  1. 组装结果无 token 超限错误（实测发送 token ≤ 预算×95%）；
  2. 各区块内容完整不截断语句（裁剪以区块为单位或按句边界）；
  3. 组装耗时 < 200ms（不含检索）。

**FR-RG-04 增量索引（P0）**
- 描述：正文保存（防抖后）/ 摘要生成 / Codex 变更时，后台队列更新对应切片，无需全量重建。
- 验收：修改某章后 30s 内检索可见新内容；索引过程不阻塞编辑（UI 线程零感知）。

### 3.8 记忆系统（MEM）

**FR-MEM-01 章后归档（P0）**
- 描述：章节"标记完成"时触发（可配置为自动）：生成本章摘要（200～400 字：事实+状态变化+伏笔动态），写入 summaries 并索引。
- 验收：摘要准确包含本章关键事实（抽检）；失败可手动重试；不阻塞下一章写作（后台执行）。

**FR-MEM-02/03/04（P1，概要）**：角色状态快照更新、伏笔登记表（状态机+写作提醒）、卷摘要滚动更新。V1.x 交付，数据结构在 V1.0 预留。

### 3.9 导出（EXP）

**FR-EXP-01 导出（P0）**
- 描述：导出范围可选（全书/单卷/多选章节）；格式：txt（章节标题+空行分段，可选去 AI 标记）、docx（标题样式/字体可配）、Markdown；epub（P1）。
- 验收：导出 100 万字 txt < 10s；docx 打开无格式错误；导出文件名含书名与日期。

### 3.10 设置（ST）

**FR-ST-01 API Key 安全存储（P0）**：Key 存于 Windows 凭据管理器（DPAPI），应用内以掩码显示；导入/导出配置不含 Key 明文（导出时可选包含，需输入密码加密）。
**FR-ST-02 生成参数（P0）**：温度、max tokens、默认续写字数、单次请求 token 上限；按场景记忆。
**FR-ST-04（P1）**：数据目录自定义（迁移时整库移动并校验完整性）。

## 4. 关键用例

### UC-01 章节续写（主用例）

** actors**：作者（主）、系统、模型 API（辅）。
**前置条件**：书已建；本章存在章纲（含出场角色）；模型已配置可用。

**主流程**：
1. 作者打开第 N 章，光标置于正文末尾；
2. 点击"续写"（Ctrl+Enter），可先填写即时指令（如"本段写打斗，主角压着打"）；
3. 系统执行上下文组装：
   a. 取常驻块：系统提示、世界观压缩卡、本卷纲要、本章章纲；
   b. 强制召回：章纲出场角色的角色卡（按 Codex 取最新状态）；
   c. 混合检索：以章纲情节点+场景关键词+实体名为查询，检索相关前文情节与设定补充，按预算取 top；
   d. 取正文尾部（默认 2500 token 滑动窗口）与最近 3 章摘要；
   e. 按 Token 预算表装配，渲染续写模板 T-06；
3. 系统流式请求模型，生成内容以草稿态实时插入；
4. 作者阅读、停止或等待完成，随后直接编辑或再次续写；
5. 作者点击"本章完成"→ 触发章后归档（摘要生成+增量索引）。

**备选流**：
- A1（3 前无章纲）：提示"本章无章纲"，提供"先生成章纲"或"仅按前文续写（降级模式，提示质量风险）"；
- A2（3 检索失败/索引未建）：降级为仅常驻块+正文尾部，界面提示"上下文降级"；
- A3（3 超出单次预算上限）：提示并在用户确认后按压缩预算重试；
- B1（4 生成中断）：保留已生成部分，标记"已中断"，可一键续传；
- C1（5 归档失败）：后台重试队列，书架角标提示待归档章节数。

**后置条件**：正文与快照已更新；AI 调用日志已记录（模板版本、模型、token、耗时）。

### UC-02 创世向导 / UC-03 批量章纲生成 / UC-04 划词润色 / UC-05 导出

## 5. 非功能需求

### 5.1 性能

| 指标 | 要求 |
|---|---|
| 续写首字延迟 | < 3s（P95，API 正常时，不含用户网络异常） |
| 检索延迟 | 10 万字库 < 500ms；50 万字 < 1.5s |
| 全量重建索引 | 10 万字 < 60s（API 嵌入） |
| 编辑器打字延迟 | 100 万字项目 < 50ms |
| 应用冷启动 | < 5s（至书架可交互） |
| 自动保存 | 防抖 ≤ 5s + 失焦即存 |
| 内存占用 | 空闲 < 500MB；100 万字项目编辑 < 1.5GB |

### 5.2 可靠性

- SQLite 开启 WAL，单写多读；库文件损坏时自动从最近备份恢复并告知；
- 每日自动备份（保留 7 天）到数据目录 `backups/`；
- AI 流式输出写入前经内容缓冲，异常不产生乱码正文；
- 崩溃上报仅含堆栈与本机环境，不含作品内容（默认关闭，需用户开启）。

### 5.3 安全与隐私

- API Key：Windows 凭据管理器（DPAPI）加密；日志与崩溃报告脱敏；
- 作品数据：仅存本地；调用模型时在设置页明示"以下内容将发送至你配置的服务"；
- 导出的备份包含全部作品数据，提供可选密码加密（AES-256）。

### 5.4 兼容性

- Win10 19044+ / Win11 x64；100%～200% DPI；
- 显示器最小支持 1280×720。

### 5.5 可用性

- 全部 AI 产出为草稿态视觉区分（浅色底纹）；
- 危险操作（删除书/章节/条目）统一二次确认模式；
- 首次启动引导：配置 Key → 3 分钟体验流程（示例书一键续写）。

### 5.6 可维护性

- 提示词模板、禁用词表、敏感词库、题材模板均为数据文件，随版本 seed 更新且不覆盖用户自定义版本；
- 核心逻辑（RAG、组装器、模板引擎）为独立 TS 包，无 UI 依赖，可单测。
