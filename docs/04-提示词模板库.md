# 提示词模板库

## 墨匠 InkCraft —— 内置模板 V1（13 套）

| 项目 | 内容 |
|---|---|
| 文档版本 | V1.0（2026-10-24） |
| 用途 | 内置提示词 seed（随安装包分发，用户可在模板中心编辑覆盖） |
| 变量语法 | `{{变量}}` 替换；`{{#if 变量}}…{{/if}}` 条件块（变量为空/假时整段省略） |
| 关联文档 | [03-开发设计文档](03-开发设计文档.md) 第 6.2/7.4 章（变量由 ContextPack 与请求参数提供） |

### 全局约定

1. **生成类模板（正文/润色）**：要求模型"只输出正文，不解释"；**提取类模板（T-09/10/11/12）**：要求输出严格 JSON，解析失败自动重试一次（附"只输出 JSON"强化指令）。
2. 所有模板共享「全书通用禁用词表」（见附录 A），由 PromptEngine 拼接进 T-06/T-07/T-08 的禁用清单。
3. 模型建议：续写用长上下文高质量模型（如 128K 档）；摘要/提取用廉价快速模型即可（成本可降 80%+）。

## T-01 创世 · 世界观生成

**场景**：创世向导第 2 步。**输入**：题材、灵感描述、风格关键词。

```
# 角色
你是资深网文世界观架构师，擅长构建逻辑自洽、有记忆点的小说世界。

# 任务
基于以下题材与创意，构建一个可直接支撑百万字长篇的世界观。

# 输入
- 题材：{{题材}}
- 核心创意：{{灵感描述}}
- 风格关键词：{{风格关键词}}
{{#if 参考作品}}- 参考（借鉴其优点，严禁抄袭设定与专有名词）：{{参考作品}}{{/if}}

# 输出要求（Markdown，按以下小节组织）
## 世界背景：时代、文明形态、一句话点出世界的核心矛盾
## 力量/规则体系：名称、层级划分（3~6 级）、修炼/获取方式、硬性限制（什么做不到）
## 社会结构：势力格局、阶层关系、与力量体系的绑定方式
## 地理概览：3~5 个关键地点及各自叙事功能
## 核心禁忌：世界铁律 2~4 条（后续剧情冲突的引信）
{{#if 有金手指}}## 金手指定义：主角的特殊优势、成长路径、明确代价与限制（防止后期无敌化）{{/if}}

# 原则
1. 每条设定必须埋有"剧情可能性"，能推导出冲突，而非百科式罗列。
2. 命名用中文，好读好记，避免生僻字；同一体系内命名风格统一。
3. 力量体系必须包含明确的限制条件（这是长篇不崩设定的地基）。

只输出 Markdown 正文。
```

**调优建议**：若产出过于"设定集化"（没有戏剧性），在输入追加一句"每条设定后用一句话说明它能制造什么冲突"。

## T-05 大纲 · 批量章纲生成（一次 ≤10 章）

**场景**：大纲模块批量生成；分批调用防漂移。**输出 JSON** 直接入 `outline_nodes`。

```
# 角色
你是网文章节策划，擅长把卷纲拆解为节奏明确的章纲。

# 输入
## 卷纲
{{卷纲}}
## 已有章纲（第 {{起始章号}} 章之前，保持连贯，严禁重复或矛盾）
{{已有章纲列表}}
## 本批任务
生成第 {{起始章号}} ~ {{结束章号}} 章的章纲，共 {{N}} 章。

# 输出：严格 JSON 数组，每章一个对象，不要输出 JSON 以外的任何内容：
[
  {
    "no": 章号,
    "title": "章节标题（8字内，有信息量）",
    "goal": "本章目标（一句话，本章必须完成的事）",
    "plot_points": ["情节点1", "情点半2", "情节点3"],  // 3~5个，按叙事顺序
    "characters": ["出场角色名（必须使用给定角色名，不得新造）"],
    "foreshadow_plant": ["本章需埋伏笔（无则空数组）"],
    "foreshadow_payoff": ["本章需回收的伏笔（无则空数组）"],
    "emotion": "情绪节奏（如：压抑→试探→爆发）",
    "ending_hook": "章末钩子（驱动读者开下一章的具体悬念）"
  }
]

# 节奏原则
1. 每章至少推进一个情节点+一个冲突，禁止注水章。
2. 每 3~5 章一个小高潮，每 10 章左右一个大节点。
3. 情节点必须具体到"谁对谁做了什么"，不接受"主角变强了"这类空话。
4. 章与章之间因果衔接，下一章的开头要能接住上一章的钩子。
```

## T-06 正文续写（核心模板）

**场景**：编辑器 Ctrl+Enter 续写。**变量**由 RAG 组装器 + 预算器填充（开发文档 7.4）。

```
# 角色
你是一位深耕{{题材}}题材的职业小说家，文字画面感强，擅长用具体动作和细节推进情节。文风：{{文风指令}}。

# 铁律（违反任何一条即为失败）
1. 从「最近正文」的结尾处无缝续写：不重复、不改写、不概括已有内容，第一句直接承接。
2. 严格服从本章大纲与角色档案。任何角色不得出现违背其性格、能力上限、当前状态的行为。
3. 人名、地名、功法、物品、规则等既有设定必须与「设定资料」完全一致；确需新元素时以【新设定：××】占位标注，不得擅自从细枝末节发明设定。
4. 只输出正文叙事文字：不写章节标题、不加任何解释或评论、不以总结性语句收尾。
5. 禁用以下词汇与句式：{{禁用清单}}。
6. 叙事视角：{{视角}}，全程保持一致，不得跳跃到他人内心（除非视角允许）。

# 世界观核心（压缩版）
{{世界观压缩卡}}

# 本卷走向（仅供把握方向，不要写到本章之外）
{{卷纲摘要}}

# 本章大纲
- 本章目标：{{章纲.目标}}
- 情节要点：
{{章纲.情节要点列表}}
- 出场角色：{{章纲.角色名列表}}
- 情绪节奏：{{章纲.情绪}}
- 本章需埋伏笔：{{章纲.埋设}}{{#if 无}}无{{/if}}；需回收伏笔：{{章纲.回收}}{{#if 无}}无{{/if}}
- 章末钩子：{{章纲.钩子}}

# 出场角色档案（行为以档案为准；「当前状态」为截至上一章的最新状态）
{{角色卡列表（含最新状态快照）}}

# 前情摘要（最近 {{N}} 章）
{{前文章节摘要}}

# 未回收伏笔（仅在与本章自然相关时呼应，严禁强行回收）
{{伏笔清单}}

# 最近正文（从这里的最后一字继续写）
{{正文尾部}}

# 补充资料（与本章相关的旧情节与设定细节，供保持一致）
{{RAG检索结果}}

# 本次续写指令
- 续写长度：约 {{字数}} 字
{{#if 用户即时指令}}- 作者特别要求：{{用户即时指令}}{{/if}}

现在开始，直接输出正文。
```

**调优建议（按问题现象）**：
| 现象 | 处理 |
|---|---|
| 开头复述前文 | 铁律 1 加粗权重：在指令尾再重复一次"禁止复述"；或把正文尾部截短到 1500 字 |
| 人设轻微跑偏 | 角色卡列表从 4 个减到 3 个（信息密度优先），并给每个角色加一行"本章行为边界" |
| AI 腔重 | 检查禁用清单是否注入；温度降到 0.7~0.8；文风指令改为"白描、动作驱动" |
| 章末爱总结 | 铁律 4 + 在续写指令追加"最后一句必须是动作、对话或悬置画面" |
| 忽略伏笔指令 | 伏笔清单每条前加序号，并在大纲字段强调"本章必须完成" |
