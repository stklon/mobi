## 一图看懂核心流程

```
创世向导（世界观/角色/总纲）
   → 三层大纲（总纲 → 卷纲 → 章纲批量生成，人工审校）
   → 章节写作循环：
       选中章纲 → RAG 上下文组装（强制召回角色卡 + 混合检索设定/前文
       + 滑动窗口正文 + 最近章摘要 + 伏笔清单，按 Token 预算装配）
       → 提示词渲染（T-06）→ LLM 流式续写 → 人工编辑/多轮续写
   → 章后归档（摘要生成 / 角色状态快照 / 伏笔登记 / 增量索引）
   → 循环下一章 … 卷末卷摘要 … 全书一致性检查 → 导出
```

## 关键设计决策速查

| 决策点 | 结论 | 出处 |
|---|---|---|
| 为什么 RAG 而非塞全文 | 百万字远超上下文窗口；按需检索 + 分层记忆摘要链才是长篇正解 | PRD 1.3 / DDD 7 |
| 检索为什么必须双通道 | 角色名等专有名词要精确命中（关键词/FTS5），语义相关情节靠向量；另有角色卡强制召回兜底 | DDD 7.3 |
| 角色不崩人设的机制 | 角色状态按章节快照，续写取"截至上一章"的最新状态注入 | DDD 6.3 |
| Token 预算怎么分配 | P0 区块（章纲/角色卡/正文尾部等）不可裁，P2（RAG 补充）超限先裁；按模型上下文档位自动缩放 | DDD 7.4 |
| 成本怎么控 | 模型分工（续写用贵模型、摘要提取用便宜模型）+ 用量统计 + 单次请求预算上限 | PRD AI-02/04 |
